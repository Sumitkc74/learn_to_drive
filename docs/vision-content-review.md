# Vision image review

Learning Content Review supports Vision tests alongside Questions and Traffic signs.
Choose Vision tests, show the category, then check the National Eye Institute source.
The parser selects the individual color plate only, excluding logos and medical equipment photographs.

Source: https://www.nei.nih.gov/eye-health-information/eye-conditions-and-diseases/color-blindness/testing-color-vision-deficiency

Verified September 11, 2026: one image discovered and collected into Pending review.
Titles come from the source image's alternative text. This is an educational reference from NIH, not a Nepal licensing examination plate.

Save a private copy, inspect the image and reuse terms, and approve the reference.
Enter the test number and confirm to add it to Vision Tests. This last action makes it available to learners.
The importer preserves the original image bytes and stores source URLs, checksum and reviewer with the media.
Duplicate images, changed files and unapproved references are blocked.

Screen-based practice does not certify vision or fitness to drive. No clinical result is inferred from the image.
