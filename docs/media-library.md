# Media Library

Open System → Media Library to browse images and PDFs attached to learning content.
Filter by content type or format, or search filenames. Images have previews; PDFs
open in a new tab. Edit Content takes you to the related record to replace a file.

Storage checks run for the current page of 24 files. Missing files are labelled;
unreachable storage is distinguished from missing files. A failed browser preview
also points you toward checking the public storage link and application URL.

User avatars and private review downloads are excluded. Private Review Files links
to Learning Content, where those files retain their existing review controls.
The library does not delete files or change their publication state.
