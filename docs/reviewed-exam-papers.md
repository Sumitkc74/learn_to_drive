# Reviewed PDFs in Question Banks

1. Open the PDF in Learning Content, save it, and inspect it.
2. Approve the reference with its actual language, licence category, edition, and review notes.
3. Use **Add to Question Banks**, enter the names and description, confirm, and add.

Each reference becomes one bank with one PDF and an English or Nepali language category.
Reviewed translations are also separate banks. Missing, changed, unapproved, oversized,
invalid, or already imported PDFs are blocked. Source files and attribution are preserved.
Approval alone does not publish the PDF; Add to Question Banks makes it available to learners.

See [Individual question banks](single-language-question-banks.md) for the storage and API changes.
